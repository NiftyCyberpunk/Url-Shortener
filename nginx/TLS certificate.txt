check the openssl is installed
openssl --version in bash 
then make the "certs" folder under "nignx" folder
run the command in the root of the directory in bash 


openssl req -x509 -nodes -days 365 -newkey rsa:2048 \
  -keyout nginx/certs/localhost.key \
  -out nginx/certs/localhost.crt \
  -subj "/CN=localhost"


self signed certificate and key will be generated
